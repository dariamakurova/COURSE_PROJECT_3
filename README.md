# Проект для работы с вакансиями HeadHunter

## Проект для сбора, обработки и анализа вакансий с платформы [hh.ru](https://hh.ru/) 
##с сохранением данных в PostgreSQL.

## Возможности

-  Сбор данных о компаниях и их вакансиях с API [hh.ru](https://hh.ru/)
-  Сохранение данных
-  Загрузка данных в базу данных PostgreSQL
-  Выполнение аналитических запросов пользователя

## Структура проекта

```bash

├── README.md
├── data
│   └── top_employers.py
├── example_database.ini        #пример заполнения database.ini - необходимо ввести данные для подключение к PostgreSQL
├── main.py
├── src
│   ├── __init__.py
│   ├── config.py
│   ├── database.ini
│   ├── db_manager.py           #модуль обработки запросов пользователя к базе данных
│   ├── employer_api.py 
│   ├── hh_api.py               #класс для получения вакансий с платформы HeadHunter
│   ├── hh_employer_api.py      #класс для получения информации о работодателе с платформы HeadHunter 
│   ├── user_interaction.py     #модуль взаимодействия с пользователем
│   ├── utils.py                #вспомогательные функции - создание и наполнение базы данных
│   └── vacancies_api.py
```

## Основные функции

Программа автоматически собирает данные о работодателях (топ-10 из data/top_employers),
сохраняет их в базу данных и предоставляет интерактивное меню для запросов пользователя.

## Примеры запросов

#### - Все компании с количеством вакансий
#### - Средняя заработная плата
#### - Вакансии с зарплатой выше средней
#### - Поиск по ключевому слову## (например, "Python", "Java", "Analyst")
#### - Сводка данных о компаниях и количестве активных вакансий

## Работа с API HeadHunter

Проект собирает данные по следующим компаниям (по умолчанию):

1. Леста Игры
2. VK
3. Ростелеком
4. Wildberries
5. Ozon
6. Яндекс
7. Т-Банк
8. Точка Банк
9. МТС
10. Сбер

Для изменения списка компаний отредактируйте список top_employers в файле data/top_employers.

## Структура базы данных

### Таблица employers

- employer_id - ID компании на [hh.ru](https://hh.ru/)
- name - название компании

### Таблица vacancies

- vacancy_id - ID вакансии на [hh.ru](https://hh.ru/)
- name - название вакансии
- employer_id - внешний ключ на employers
- salary_from, salary_to - зарплата
- salary_currency - валюта
- requirement - требования
- url - ссылка на вакансию
